# Release Notes

Version v0.5.6 — November 2, 2026

## Squad counts

- Squad members who were in the squad but never fought (no hits, no
  casts, never entered combat) no longer count toward the squad, so
  squad sizes and squad-wide numbers match Elite Insights.
- Allies on the newest arcdps build no longer show up as enemies, and
  squad members that arcdps tags with a bogus team no longer get filed
  as enemies either.

## Fixes

- Cleanses and boon strips are counted the way the arcdps meter counts
  them.
- More skills show their real name instead of a bare id.
